# Claude-Beauty-Salon — DECISIONS

## 2026-10-15: Название Claude-Beauty-Salon

**Контекст:** Нужен репозиторий-коллекция по треду «10 репозиториев, превращающих Claude Code в elite UI-дизайнера». Пользователь просил красивое юморное название.

**Решение:** Claude-Beauty-Salon — салон красоты для AI-дизайнера.

**Альтернативы:** AntiSlop-Atelier, TastePolice, Neuro-Visagiste.

**Trade-off:** Шутливое имя менее формально для серьёзных заказчиков, но репо личное, не клиентское.

## 2026-10-15: Вся добыча в одном файле docs/COLLECTION.md

**Контекст:** Стандарт запрещает новые .md без разрешения, но задача — именно коллекция ссылок и идей.

**Решение:** Создать docs/COLLECTION.md как исключение, с явного разрешения пользователя («размести там все идеи»). Фиксирую здесь, чтобы будущие агенты не удаляли как «лишний файл».

**Альтернативы:** Всё в README (нарушит лимит 100 строк), всё в CONTEXT (смешает состояние и контент).

**Trade-off:** Один длинный файл вместо нескольких тематических; если коллекция вырастет — делить по разделам внутри, не новыми файлами.

## 2026-10-15: Markdown-only, без кода и зависимостей

**Контекст:** Репо — база знаний, ставить и собирать нечего.

**Решение:** Никаких package.json, тестов, сборок. Только проверенные ссылки и команды установки для копипасты.

**Альтернативы:** Сабмодули/клоны 10 репозиториев внутрь.

**Trade-off:** Ссылки могут протухнуть; плюс — репо весит килобайты и не требует поддержки.
