Разбор поста RoundtableSpace «10 github repos that turn claude code and codex into elite ui designers»: что реально полезно, что — каталог идей, что — пропустить. Плюс все ссылки, демо-сайты и привязка к моим проектам.

- **Вердикт** — 4 брать, 3 как витрину идей, 2 пропустить
- **Вся добыча** — в одном файле с командами установки
- **Красивые сайты** — куда сходить глазами за вкусом
- **Привязка к проектам** — суды, заводы, SEO, 3D
